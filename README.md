# CSS-Selector-Task3

## Project Overview

This project demonstrates the use of different CSS selectors such as Class Selector, ID Selector, and Element Selector. The webpage contains headings, paragraphs, and list items styled using external CSS.

## Features

* Class Selector (`.head`) used for styling multiple headings.
* ID Selector (`#bglime`) used for styling a specific heading.
* Element Selector (`p`) used for styling all paragraph elements.
* Custom styling applied to `<mark>` elements.
* Background color added to the webpage.

## Files Used

### 1. index.html

Contains the structure of the webpage:

* Headings (h1, h2, h3)
* Paragraphs
* Unordered List
* Marked text

### 2. style.css

Contains CSS styling rules:

* `.head` → Changes heading color to dark blue.
* `#bglime` → Adds aqua background color to the h2 heading.
* `.head2` → Changes only the word "head" inside h2 to red.
* `p` → Changes paragraph text color to orange.
* `#para` → Changes paragraph color to green and increases font size.
* `.paragraph` → Changes marked word color to black.
* `mark` → Changes marked text color to blue and makes it bold.

## CSS Selectors Used

| Selector     | Purpose                                 |
| ------------ | --------------------------------------- |
| `.head`      | Styles all elements having class "head" |
| `#bglime`    | Styles the element having id "bglime"   |
| `p`          | Styles all paragraph elements           |
| `.head2`     | Styles the marked word "head" in h2     |
| `.paragraph` | Styles the marked word "paragraph"      |

## Output

The webpage displays:

* Dark blue headings.
* Aqua background for the h2 heading.
* Red color for the highlighted word "head".
* Orange paragraphs.
* Green styled paragraph with larger font size.
* Blue bold highlighted text inside `<mark>` tags.
